# Ytutor AI - Frontend

This is the frontend application for Ytutor AI, built with React, Vite, and TailwindCSS.

For comprehensive project documentation, architecture diagrams, and full setup instructions, please see the [Main Project README](../README.md) located in the root directory.

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

*Note: The frontend expects the backend FastAPI server to be running on `http://localhost:8000` by default. If your backend is hosted elsewhere, create a `.env` file and set `VITE_API_URL=your_backend_url`.*
